## 기능 구현 목록

### 입력

-[x] 콘솔에서 문자열 입력
-[x] 빈 입력 처리 시 기본값 ("")반환

### 검증

-[x] 커스텀 구분자 형식 검증 (//[구분자]\n)
-[x] 구분자가 1개의 문자인지 검증
-[ ] 숫자가 양의 정수인지 검증 (음수, 0, 소수 예외처리)
-[ ] 입력값이 비어 있는지 검증
-[ ] 구분자와 숫자 외의 문자 존재 검증

### 파싱

-[x] 커스텀 구분자 추출
-[x] 본문 추출 (커스텀 구분자 이후의 문자열)
-[x] 구분자 목록 구성
    -[x] 기본 구분자: 쉼표(,), 콜론(:)
    -[x] 커스텀 구분자
-[x] 구분자를 이용한 본문 문자열 분리
-[ ] 분리된 문자열 정수 리스트로 변환
-[ ] 변환 과정 중 파싱 불가능한 값 존재 시 예외 발생

### 계산

-[ ] 주어진 숫자 리스트의 합 계산
-[ ] 빈 리스트의 경우 0 반환

### 출력

-[x] "결과 : {숫자}" 형태로 출력
